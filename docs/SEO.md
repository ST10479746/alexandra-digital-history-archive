### Project-path robots limitation

A crawler reads robots.txt at the origin root, not inside a project subdirectory. On a project-based GitHub Pages site, the robots.txt included here will be published under the repository path and will not control crawling for emgpsd.github.io. Do not claim that it does. Page-level robots metadata is included, and sitemap.xml can be submitted directly in Search Console after ownership verification. To make the file authoritative, it would need to be hosted at the origin root by its owner or on a deployment served from its own origin root.
